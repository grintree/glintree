Glintree V2.0 更新说明

本次更新围绕「macOS 风格界面重构」展开，同时修复数据库问题、补齐流程编辑器半成品功能、放大全局字体，并完成全套构建修复。以下为本版本全部更新内容汇总。

发布日期：2026-08

◐整体视觉

  • 全局底色切换为 macOS 浅灰 #F5F5F7
  • 强调色统一为系统蓝 #0A84FF
  • 全局圆角 8px、细边框、柔和阴影
  • 字体改为 Microsoft YaHei UI 并整体放大两级
  • 界面根据屏幕分辨率与 DPI 自动缩放，适配不同电脑屏幕
  • 应用图标统一使用项目根目录 logo.ico

☷数据查看

  • 数据表格、执行日志、分页条统一 macOS 风格
  • 导出数据弹窗（Excel/CSV）同步更新

✎功能补齐

  • 点击元素：Ajax 加载、页面加速、锚点、自动重试
  • 打开网页：自定义 Cookie、清缓存、超时重试
  • 新增验证码步骤（截图 + 手动输入）
  • 新增下拉切换、判断条件、结束循环、结束

▣问题修复

  • 清空任务数据判断逻辑修复
  • QWebEngineProfile 未定义类型修复
  • 嵌套 lambda 捕获错误修复（MSVC）
  • MSVC + Qt 6.8.3 全量编译链接通过

首页任务编排 流程步骤 浏览器区域 属性面板 任务管理 数据查看 执行日志 分页条 设置 关于 启动设置弹窗 导出数据弹窗 验证码弹窗 消息框 菜单 工具栏 表格 滚动条 复选框 进度条 工具提示
