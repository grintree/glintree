# Glintree

Glintree 是一款基于 **Qt 6 + QtWebEngine** 的桌面数据采集工具（RPA 式流程编排），无需编写代码即可完成“打开网页 → 操作元素 → 提取数据 → 入库/导出”的自动化任务。

> 当前版本：**V2.0**

---

## 功能特性

### 可视化流程编排
- 左侧控件栏拖拽式搭建流程，共 11 种步骤：
  **打开网页、点击元素、提取数据、输入文字、验证码、切换下拉选项、判断条件、循环、移动鼠标、结束循环、结束**
- 支持循环类型：单个元素翻页、网址列表、固定元素、不固定元素
- 判断条件：元素存在 / 元素文本等于 / 元素文本包含，条件不成立自动跳过判断块
- 验证码步骤：网页截图 → 弹窗手动输入 → 自动填入，支持跳过
- 点击步骤高级选项：Ajax 加载与超时、页面加速、定位锚点、自动重试、新标签打开、滚动页面
- 打开网页高级选项：自定义 Cookie、打开前清理缓存、加载超时自动重试、阻止弹窗、滚动

### 智能提示选元素
- 在网页上点击任意元素，自动识别同类元素与 XPath
- 一键生成“采集文本 / 链接 / 图片地址 / 内/外 HTML”等提取规则
- 支持“选中全部”批量生成循环 + 提取 / 循环 + 点击

### 任务与数据管理
- 多任务并行管理，任务分组、编辑、删除、导入/导出（`.ds` 文件）
- 采集数据自动去重入库（SQLite），支持循环周期采集
- 数据查看分页、执行日志、导出 Excel（xlsx）/ CSV、字段批量下载

### 界面与体验
- macOS 风格界面：浅灰底色、系统蓝强调色、圆角卡片、统一字体
- 界面按屏幕分辨率与 DPI 自动缩放（1080P 基准，1.0 ~ 1.75）
- 全局字体放大，适合长时间查看

### 其它
- 检查更新、清空浏览器缓存、手动 HTTP 代理
- 崩溃信息上报与心跳（服务器地址见 `Utils/constant.h` 的 `HOST`，当前为占位符）
- 帮助 → 更新说明：打开 V2.0 更新汇总 HTML（随程序资源打包，自动释放到本地）

## 构建方法

### 环境要求

- Windows 10 / 11 64 位
- Qt 6.8+（推荐 **Qt 6.8.3 MSVC2022 64-bit**，需包含模块：`webenginewidgets`、`core5compat`、`sql`）
- 编译器：MSVC 2022 或 MinGW 13

> ⚠️ 注意：如果使用 MinGW 套件，必须确认该 Qt 安装包含 QtWebEngine 与 Qt Core5Compat 模块；否则请使用 MSVC 套件（项目已在 Qt 6.8.3 MSVC 下验证通过）。

### Qt Creator

1. 工具 → 选项 → Kits → Qt Versions，添加 `E:\Qt\6.8.3\msvc2022_64\bin\qmake.exe`
2. 选择 **Desktop Qt 6.8.3 MSVC2022 64-bit** 套件打开 `Glintree.pro`
3. 点击“构建”即可

### 命令行

```powershell
mkdir build
cd build
"qmake.exe" ..\Glintree.pro
nmake        # 需先执行 vcvars64.bat 进入 VS 开发环境
```

构建产物：`build\release\Glintree.exe`

## 快速上手

1. **新建任务**：首页输入目标网址 → 新建任务
2. **编排流程**：左侧拖入步骤；网页上点击元素可用“智能提示”生成点击/提取规则；在右侧属性面板保存参数
3. **保存任务**：任务会序列化到 SQLite（`ds_task` 表）
4. **执行任务**：任务管理 → 执行任务，选择直接启动或定时循环启动
5. **查看数据**：任务管理 → 管理数据；可导出 Excel / CSV 或按字段批量下载

### 任务文件格式

任务可导出为 `.ds` 文件（Base64 编码），导入后自动分配新任务编号。
